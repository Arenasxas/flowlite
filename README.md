# FlowLite

Dictado por voz y apuntes automáticos de clases, reuniones y llamadas. Funciona en la PC con Windows y en el celular, con Android y iPhone.

- **PC:** `flowlite.py`, la app de Windows. Se arma con `python build.py --instalar`.
- **Celular:** `mobile/`, una app web instalable. Se publica en https://arenasxas.github.io/flowlite/
- **Compartido:** `shared/`, con las indicaciones para la IA y el formato del cuaderno. Lo usan los dos lados.
- **Android:** `android/`, una app nativa con teclado de dictado. El APK se baja en *Releases*.
- **Guía completa** (qué hace cada parte, cómo compilar y probar, y los pasos a mano): [docs/GUIA.md](docs/GUIA.md).

Las claves de Groq y Gemini nunca van al repo. Cada uno pega las suyas en Ajustes.
